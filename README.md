# GitVela

GitVela is a read-only Windows desktop client for browsing local Git repositories. Open a folder, select a commit, and choose a file to compare its two versions. For a merge commit, select the parent to compare against.

See [GitVela.md](GitVela.md) for the architecture and roadmap.

## Windows development

Run from the project root in a PowerShell session with Go, Git and fnm available. Wails and its JavaScript runtime are pinned to 3.1.0. Node.js 24 is selected per session.

```powershell
fnm env --shell powershell | Out-String | Invoke-Expression
fnm install 24
fnm use 24
$env:GOTOOLCHAIN = 'go1.27.3'
$env:GOBIN = Join-Path $PWD '.tools/bin'
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0
$gitRoot = Split-Path (Split-Path (Get-Command git).Source)
$env:Path = "$env:GOBIN;$gitRoot/usr/bin;$env:Path"
wails3 doctor
wails3 dev
```

Stop the dev process before running a production build. Both modes write to the same output directory.

```powershell
wails3 build
go test ./...
go vet ./...
npm --prefix frontend run typecheck
npm --prefix frontend test
```

The production executable is at `bin/gitvela.exe`. Bindings are generated by the Wails build.

## Desktop smoke test

Start `wails3 dev -tags desktop_smoke` to enable WebView2 debugging on port 9331 using an isolated profile under `.tools`. In a second PowerShell session with fnm initialized and Node 24 selected, run `node tests/desktop-smoke.mjs` from the project root. The smoke test opens this repository and checks the initial commit's real Git diff through the desktop UI.

```powershell
go test ./internal/git -run '^$' -bench BenchmarkReadHistoryAndDiff -benchmem -benchtime 5x
```

The benchmark creates a temporary 10,000-commit repository. It measures Go and Git CLI time, excluding WebView rendering.
